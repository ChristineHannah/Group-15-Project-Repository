## 1. Purpose

This program calculates OLS coefficients by solving the normal equations:

`(X^T X)β = X^T y`

The design matrix `X` must already contain the intercept and any feature columns. Polynomial features are not generated by this program.

## 2. Program files

- `polynomial_regression.hpp` defines the `Vector<T>` container and declares `computeNormalEquations` and `fitOLS`.
- `polynomial_regression.cpp` implements these functions and includes a small example in `main`.

## 3. Method

`computeNormalEquations` checks that the design matrix is not empty and that every row has the same number of columns. It calculates each element of `X^T X` by summing products from the input rows.

`fitOLS` checks that `X` and `y` have the same number of rows. It forms `X^T y`, then uses Gaussian elimination with partial pivoting and back substitution to find the coefficients. Invalid dimensions and near-zero pivots are reported as errors.

The custom `Vector<T>` stores values in arrays and allows the design matrix to be represented as a vector of rows. Direct accumulation avoids creating a separate transposed matrix. Partial pivoting helps reduce numerical error during the solve.

## 4. Example and results

The example uses:

```
X = [[1, 1],
     [1, 2],
     [1, 3]]
y = [3, 5, 7]
```

The program calculates:

```
X^T X = [[3, 6],
         [6, 14]]
X^T y = [15, 34]
```

The resulting intercept is `1` and slope is `2`, giving `y = 1 + 2x`. This matches all three example targets.

## 5. Limitations

The example data is hard-coded. Callers must prepare the intercept and feature columns themselves. The `Vector<T>` constructor rejects negative sizes, and its indexed accessors check bounds. The normal equations can be inaccurate for poorly conditioned data, and the pivot check uses a fixed threshold of `1e-12`.

## 6. Conclusion

The program demonstrates the main OLS steps: form `X^T X` and `X^T y`, then solve for the coefficients. Its example confirms the expected line, `y = 1 + 2x`.
